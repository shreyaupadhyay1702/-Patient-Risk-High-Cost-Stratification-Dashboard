# 🏥 Patient Risk & High-Cost Stratification Dashboard

📊 An interactive **Healthcare Analytics Dashboard** built using **Python, SQL, Power BI, and DAX** to analyze patient risk, billing, medical conditions, insurance providers, hospital financial exposure, and high-value patients.

---

## 🛠️ Tools & Technologies

- 🐍 **Python** – Data cleaning and preprocessing
- 🗄️ **SQL** – Data transformation and feature engineering
- 🔀 **CASE WHEN** – Patient risk/high-value categorization
- 📈 **Window Functions** – Ranking and analytical calculations
- 📊 **Power BI** – Interactive dashboard and visualization
- 🧮 **DAX** – Dynamic dashboard metrics

---

## 🔄 Project Workflow

**Raw Healthcare Data → Python Cleaning → SQL Feature Engineering → Power BI → DAX → Interactive Dashboard**

---

## 🐍 Python – Data Cleaning

Python was used to prepare the healthcare dataset for analysis.

Key activities:

- Cleaned and standardized the data
- Handled missing and duplicate values
- Checked data types
- Prepared the dataset for SQL and Power BI

---

## 🗄️ SQL – Feature Engineering

SQL was used to create meaningful analytical features from the cleaned data.

Key techniques:

- Aggregation and grouping
- `CASE WHEN` for patient categorization
- Window Functions for patient billing ranking
- Medical condition and hospital-level analysis
- Financial exposure analysis

---

## 📊 Power BI Dashboard

The dashboard provides an interactive view of **patient risk and healthcare financial performance**.

### Key Dashboard Metrics

- 💰 **Total Revenue:** 1,403.15M
- 👥 **Total Patients:** 55K
- 🏥 **Average Length of Stay:** 15.50
- 🚨 **High Value Patients:** 27K

### Dashboard Visuals

- 🏦 Insurance Provider Risk Share
- 💰 Top 5 Hospitals by Financial Exposure
- 📊 Average Billing Amount by Length of Stay
- 👥 Patient-level billing and ranking table
- 🎯 Interactive filters for:
  - High Value Patient
  - Medical Condition
  - Insurance Provider

---

## 🧮 DAX Measures

DAX was used to create dynamic dashboard metrics such as:

- Total Revenue
- Total Patients
- Average Length of Stay
- High Value Patient Count
- Billing Amount
- Risk Share
- Other dashboard KPIs

These measures allow the dashboard to update dynamically based on selected filters.
